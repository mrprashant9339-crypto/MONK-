2. Added `public.update_task_details(uuid,text,text,date)`:
   - Requires authenticated user and active organization.
   - Locks and checks the task inside the active organization.
   - Requires owner/admin/manager, or assigned contributor/vendor.

5. Frontend task rows now expose edit and archive actions.
